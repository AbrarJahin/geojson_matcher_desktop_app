# Third-party notices

This project depends on PySide6/Qt, GeoPandas, Shapely, PyProj, Pyogrio, scikit-learn, SciPy, NumPy, pandas, Matplotlib, RapidFuzz, and their transitive dependencies.

The optional online review basemap uses OpenStreetMap raster tiles and displays the required attribution in the map. Any distributed or hosted use must comply with the OpenStreetMap tile usage policy and attribution requirements.

Before distributing an installer, collect and include the license texts required by the exact dependency versions installed in the build environment. In particular, review the LGPL/GPL/commercial licensing options applicable to PySide6 and Qt and ensure the selected distribution model satisfies those terms.
